# Pie de Rey Virtual

Simulador interactivo de pie de rey (calibrador Vernier) para la asignatura
**Máquinas Herramientas**, carrera de Electromecánica — Universidad UTE.

Página única, sin dependencias ni servidor: se abre directamente en el teléfono.

- Apreciación seleccionable: 0,1 / 0,05 / 0,02 mm
- Lupa de lectura con la coincidencia del nonio resaltada
- Modo práctica con lecturas aleatorias y corrección automática
- Banco de piezas con verificación contra tolerancia

Autor: Ing. David Sarzosa
